1. ข้อมูลจำเพาะของบอร์ดควบคุม (Hardware Specifications)

ESP32-S3: ความเร็ว 240 MHz Dual-core, SRAM 512KB, Flash 8MB ทำหน้าที่อ่านเซนเซอร์ Modbus RS-485 และประมวลผลลอจิกตัดรอบปั๊มน้ำ 90% -> 80% (+8,400 ลิตร)

Raspberry Pi 3 Model B+: 64-bit 1.4 GHz, RAM 1GB ทำหน้าที่เป็น MQTT Broker, Data Logging และจัดทำรายงานรายวัน/รายเดือน

2. มิติถังพักและการคำนวณปริมาตรไฮดรอลิกส์

ถังพักน้ำเสียขนาด กว้าง 3.0m x ยาว 4.0m x ลึก 7.0m ปริมาตรรวม 84.0 m³

ลูกลอย FS-H สั่งเริ่มสูบที่ 90% (6.30m) และ FS-L สั่งหยุดสูบที่ 80% (5.60m) ความสูงลดลง 0.70m

ปริมาตรน้ำที่สูบออกต่อ 1 รอบ = 3 x 4 x 0.70 = 8.40 m³ = 8,400 ลิตร

3. การแก้ไขปัญหาเบื้องต้นหน้างาน (Troubleshooting Matrix)

  • ปั๊มไม่ยอมตัดเมื่อน้ำลด: ให้หมุนสวิตช์หน้าตู้ไปที่ OFF ทันที ตรวจสอบลูกลอย FS-L ทำความสะอาดคราบไขมัน
  • ไฟ Overload Trip ติดค้าง: สับเบรกเกอร์ลง ตรวจสอบเศษขยะอุดตันใบพัดปั๊ม และกดปุ่ม Reset สีฟ้าบน Thermal Overload
  • ค่า pH หรือ DO ไม่ขึ้น: ตรวจสอบสาย RS-485 ขั้ว A-B และล้างคราบเมือกแบคทีเรียบนหัวโพรบ

4. คำถามที่พบบ่อย (FAQ)

ถาม: หากเน็ตหลุด ตู้ควบคุมยังทำงานอัตโนมัติได้หรือไม่?
ตอบ: ทำงานได้ตามปกติ 100% ลอจิกทำงานบนบอร์ด ESP32 โดยตรง ไม่ได้พึ่งพาคลาวด์

ถาม: ความปลอดภัยด้านไฟฟ้าและเคมีมีข้อควรระวังใดบ้าง?
ตอบ: ต้องปฏิบัติตามมาตรฐาน LOTO ตัดไฟทุกครั้งก่อนเปิดตู้ และห้ามลงบ่อพักน้ำเสียโดยไม่มีอุปกรณ์ตรวจวัดก๊าซและหน้ากาก SCBA
